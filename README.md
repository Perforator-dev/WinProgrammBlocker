
A useful blocker for your computer. It takes up less than 10 MB of RAM and has a simple interface. When minimized, it appears in the system tray. You can view all files, as it's open source. My Discord server https://discord.gg/rUM2RB5tn

The program retrieves data about running programs from the Task Manager and automatically closes them when they are moved to the list of blocked programs. You can block up to 100 programs or more with this program. Another advantage of the program is its low memory usage-less than 10 MB.
